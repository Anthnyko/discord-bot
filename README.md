# Discord Bot (Python + discord.py) 🚀

A fully modular Discord bot built with Python and discord.py, designed with clean architecture, cog‑based organization, and extensibility in mind.  
This project demonstrates event handling, API integration, command organization, and basic moderation logic.

---

## 🔧 Tech Stack

- **Python 3.10+**
- **discord.py 2.x**
- **aiohttp** for API requests
- **dotenv** for environment variables
- **JSON-based storage** for lightweight persistence

---

## 🧠 Core Features

### 🎮 Fun Module
- Dice rolls, coin flips, 8‑ball responses  
- Random memes, dogs, and cats via public APIs  
- Roasts and compliments

### 🛠 Utility Module
- Reaction polls  
- DM reminders  
- User/server info  
- Quick DM replies

### 💬 Social Module
- Quote saving  
- Quote history

### 📢 Events Module
- Welcome messages  
- Keyword triggers  
- Basic profanity filtering  
- Custom `on_message` logic
